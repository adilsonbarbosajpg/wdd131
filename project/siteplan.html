GZ

Gaming Zone

This name represents a website focused on gaming information, tips, and resources for players.

Site Purpose

On this site, users will be able to find the best ways to improve their FPS gaming experience.

Scenarios

  • How can I improve my FPS?
  • How can I find the best sensitivity?

Color Schema

  • Dark background (#121212) will be used as the main background of the website.
  • Purple (#9B59FF) will be used for headings, buttons, and accents.

Typography

Roboto will be used for headings, paragraphs, and navigation.
